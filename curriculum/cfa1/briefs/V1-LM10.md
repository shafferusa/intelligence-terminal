## Core principles

- **OLS picks the best line, not a good one.** The error term absorbs everything omitted, so points miss the line. OLS minimizes squared vertical misses; fit quality is judged separately by R², SEE and F (p.514, p.530).
- **Slope is covariance over variance; the line runs through the sample means,** so residuals sum to zero. Residuals are computed; true errors are unobservable (p.517–518).
- **A dummy variable equals a difference in group means.** Intercept is the mean when the flag is 0; intercept plus slope is the mean when it is 1. The slope's t-test asks whether the event changed the average (p.516).
- **Four assumptions, all about errors:** linear in parameters, constant variance, uncorrelated errors, normal errors. A curve in residuals means non-linearity, a fan means heteroskedasticity, a time pattern means autocorrelation. Y itself need not be normal (p.524–529; Knowledge Check PDF 539).
- **Variation splits into explained and unexplained.** R² is the explained share and only describes. F and t test significance, and for one regressor they agree. SEE is the typical miss in Y's units (p.530–535).
- **Forecast risk has three layers:** scatter around the line, uncertainty in the estimated coefficients, and distance of the forecast X from the mean of X. Extrapolating widens the interval; it fails if the relationship shifts (p.540–541).
- **Logs rescue curved relationships.** Log-lin: a one-unit rise in X gives a constant percentage change in Y. Lin-log: a 1% rise in X gives a constant absolute change in Y. Log-log: slope is elasticity. Choose by theory, then residuals and fit; compare SEE and R² only for the same form of Y (p.543–548).
- **CAPM beta is a regression slope.** Regress the asset's excess returns on the market's excess returns. Only market (systematic) risk is rewarded; the regression R² is read as the systematic share of variance. It relies on a broad index and one factor; evidence is mixed but use is widespread for cost of capital and performance evaluation (p.556–563).

## Vocabulary

- Least squares (OLS) — minimize the sum of squared vertical gaps (p.514).
- Error term vs residual — true unobservable deviation vs estimated gap (p.517–518).
- Indicator (dummy) variable — 0/1 flag for a condition (p.516).
- SSE, SSR, SST — unexplained, explained, total squared variation (p.518, p.530).
- Cross-sectional, time-series, panel data — many entities once, one entity over time, both (p.521–522).
- Homoskedasticity / heteroskedasticity — constant vs changing error variance (p.526).
- R² — share of Y's variation explained (p.532).
- F-statistic, MSR, MSE — explained over unexplained variation per degree of freedom (p.533–534).
- SEE — square root of MSE; scatter around the line (p.535).
- Type I / II error; p-value — false rejection / false non-rejection; smallest significance level rejecting H0 (p.537).
- Standard error of the forecast; prediction interval (p.540–541).
- Log-lin, lin-log, log-log — logs on Y, X or both (p.543).
- Beta, market risk premium, excess return (p.556–557).

## Formulas

1. Model: Y_i = b0 + b1·X_i + e_i (p.515; PDF 525). b0 in Y units, b1 in Y per X unit; e the true error.
2. Fitted and residual: Yhat_i = b0hat + b1hat·X_i; e_i = Y_i − Yhat_i (p.517).
3. SSE = Σ e_i² = Σ (Y_i − Yhat_i)² (p.518). OLS minimizes it.
4. Slope: b1hat = Cov(X,Y)/Var(X) = Σ[(Y_i−Ybar)(X_i−Xbar)] / Σ[(X_i−Xbar)²] (p.518).
5. Intercept: b0hat = Ybar − b1hat·Xbar (p.518).
6. SST = Σ(Y_i−Ybar)²; SSR = Σ(Yhat_i−Ybar)²; SST = SSR + SSE (p.530). Variance of Y = SST/(n−1).
7. R² = SSR/SST; simple regression only: r² = R², sign of r follows slope (p.532–533).
8. F = MSR/MSE; MSR = SSR/k (k = 1); MSE = SSE/(n−2); df 1 and n−2; tests H0: b1 = 0 (p.533–534). ANOVA df: 1, n−2, total n−1. For one regressor F = t² (my check; the book says only that the tests agree).
9. SEE = √MSE = √(SSE/(n−2)) (p.535).
10. Slope t: t = (b1hat − B1)/s_b1, df n−2; s_b1 = s_e/√Σ(X_i−Xbar)² (p.536).
11. Intercept t: t = (b0hat − B0)/s_b0; s_b0 = s_e·√(1/n + Xbar²/Σ(X_i−Xbar)²) (p.536).
12. Forecast: Yf = b0hat + b1hat·Xf (p.540).
13. Forecast SE: s_f = s_e·√(1 + 1/n + (Xf−Xbar)²/Σ(X_i−Xbar)²) (p.540).
14. Prediction interval: Yf ± t(α/2)·s_f; df n−2 (book leaves df implicit) (p.541).
15. Log forms: ln Y = b0 + b1X; Y = b0 + b1 ln X; ln Y = b0 + b1 ln X (p.544, p.546). Log-lin forecast: exponentiate predicted ln Y. Percent change in Y per unit X is e^b1 − 1, about 100·b1 % only if b1 is small (p.555).
16. CAPM: E[r_i] = r_f + β_i(E[r_m] − r_f); excess form E[r_i] − r_f = β_i(E[r_m] − r_f); regression Z_i = b0 + b1·Z_m + e, Z = return − r_f, b1hat = beta (p.556–557).
17. Coefficient CI: b1hat ± critical value × s_b1 (p.559–560). Same idea as the prediction interval, not a new formula.

## Traps

- Normality applies to the errors, not to Y (p.524–529).
- Minimized SSE is not good fit; R² is not a test (p.530, p.533).
- r = √R² only in simple regression, with the slope's sign.
- Four different standard errors (SEE, slope, intercept, forecast); read which is asked.
- Degrees of freedom: n−2 for t, MSE, SEE; n−1 for variance of Y; 1 for MSR.
- Log-lin percent change is e^b1 − 1; lin-log change in Y is b1 times the percent change in X; percentage points differ from percent (p.543–548, p.555).
- CAPM regression uses excess returns for both asset and market (p.557). Beta is the slope; R² is not beta.
- Say "reject" or "fail to reject" H0, never "accept" (p.560, p.571).

## Original practice seeds

All hypothetical.

**A. Beta.** Monthly: excess return = 0.2% + 1.2 × market excess. Premium 5% gives 0.2 + 6 = 6.2%; premium 3% gives 0.2 + 3.6 = 3.8%, a fall of 2.4 points (1.2 × 2).

**B. Fit.** n = 12, SSR = 30, SSE = 20. SST 50; R² 0.60; r 0.775 (positive slope); MSE 2; SEE 1.414; F = 15 on 1 and 10 df. If SSE were 40: R² 0.4286, MSE 4, SEE 2, F 7.5.

**C. Interval.** Yhat = 2 + 0.5X, n = 25, s_e = 1, Xbar = 8, Σ(X−Xbar)² = 100, t(23 df) = 2.069. Xf = 10: forecast 7, s_f = √1.08 = 1.039, interval 4.85 to 9.15. Xf = 18: forecast 11, s_f = √2.04 = 1.428, interval 8.05 to 13.96; wider because 18 is far from the mean.
