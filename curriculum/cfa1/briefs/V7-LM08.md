## Core principles

- **Option payoff is one-sided.** The buyer pays a premium for a right, not an obligation. A forward costs nothing at start and binds both sides. The buyer's worst case is the premium, so the writer carries the open-ended risk (pp.175, 184–185).
- **Price = exercise value + time value.** Exercise value compares spot with PV(X), because X is paid later. Time value is positive before expiry and decays to zero at expiry; the buyer pays the decay and the seller collects it. Zero exercise value does not mean zero price (pp.179, 182).
- **Moneyness uses X, exercise value uses PV(X).** Moneyness only classifies spot against X, and signals sensitivity: deep ITM options move nearly one-for-one with the underlying, deep OTM ones barely react (pp.180–181).
- **No-arbitrage gives bounds, not one price.** A call is worth at least its exercise value and at most the spot price. A put is worth at least its exercise value and at most X (the book's cap). A quote below the lower bound lets someone buy, exercise and lock in profit (pp.185–186).
- **Replication is static for forwards, dynamic for options.** A forward settles with certainty, so you borrow the full present value once. An option may never be exercised, so you hold a fraction tied to exercise likelihood and rebalance. Call: borrow and hold the underlying. Put: short the underlying and lend. Selling the option means the opposite trades (pp.186–189).
- **Forward value is linear in spot, option value is curved.** The option floors at zero, while the forward keeps losing (pp.179, 183, 190).
- **Volatility helps both calls and puts.** The buyer's loss is capped at the premium while a wider spread adds profitable outcomes (p.192).
- **Rates act through PV(X); income goes to the asset owner.** A higher rate shrinks PV(X), lifting call and cutting put exercise value if in the money. Income on the underlying lowers calls and raises puts; carry costs do the reverse (pp.192–193).

## Vocabulary

- Contingent claim — payoff depends on a choice or condition at the holder's discretion (p.175).
- Premium — upfront price paid by the buyer to the writer (pp.184–185).
- European option — exercisable only at expiry (pp.175, 179).
- Exercise value (intrinsic value) — payoff if exercised now, using PV(X) (p.179).
- Moneyness — spot relative to X: ITM, ATM or OTM (p.180).
- Time value — option price minus exercise value; decay is its shrinkage to zero (p.182).
- Payoff vs profit — profit subtracts the premium (p.185).
- Replication / dynamic replication — copying payoffs with the underlying plus borrowing or lending; rebalancing as exercise likelihood changes (pp.186–187).
- Convenience yield — non-cash benefit of holding the asset, accruing to the owner (p.193).

## Formulas

European options, no income or cost on the underlying (except the factor directions). r is the annual rate (discrete compounding, decimal); T − t is years remaining. PV(X) = X(1+r)^−(T−t).

1. **Call exercise value (Eq. 1)** = Max(0, S_t − X(1+r)^−(T−t)). (p.179).
2. **Put exercise value (Eq. 2)** = Max(0, X(1+r)^−(T−t) − S_t) (p.179).
3. **Call time value (Eq. 3)** = c_t − Max(0, S_t − X(1+r)^−(T−t)), so c_t = exercise value + time value (p.182).
4. **Put time value (Eq. 4)** = p_t − Max(0, X(1+r)^−(T−t) − S_t) (p.182).
5. **Payoffs at maturity (Eq. 5–6)**: c_T = Max(0, S_T − X); p_T = Max(0, X − S_T) (p.185).
6. **Buyer profit (Eq. 7–8)**: Max(0, S_T − X) − c_0 for a call; Max(0, X − S_T) − p_0 for a put. Ignores time value of money on the premium (p.185).
7. **Call bounds (Eq. 9–11)**: Max(0, S_t − X(1+r)^−(T−t)) < c_t ≤ S_t. The lower bound is printed with a strict inequality (p.185).
8. **Put bounds (Eq. 12–14)**: Max(0, X(1+r)^−(T−t) − S_t) < p_t ≤ X. The book caps the put at X, not PV(X), so follow that on the exam (p.186).
9. **Forward special case**: if X = F_0(T) and S_t > PV(X), the call's exercise value equals the long forward's value, S_t − PV(F_0(T)) (p.179).
10. **Recap**: S_0 = S_T(1+r)^−T for an asset with a known future price and no cash flows (p.184, PDF 192).

**Direction of effect of an increase in each factor (p.193, PDF 201):** underlying: call +, put −. Exercise price: call −, put +. Time: call +, put +/−. Risk-free rate: call +, put −. Volatility: +, +. Income: call −, put +. Carry cost: call +, put −.

## Traps

- Using X rather than PV(X) in exercise value. Discount the strike, never the spot (p.179).
- Mixing moneyness (undiscounted X) with exercise value (PV(X)) (pp.180–181).
- Treating zero exercise value as zero price; such an option is pure time value (p.182).
- Calling time value constant. It decays to zero at expiry, and the curve is concave (p.182).
- Confusing payoff with profit; exercise value ignores the premium (pp.180, 185).
- Wrong caps: call capped at S_t, put at X; lower bounds use PV(X) and floor at zero (pp.185–186).
- Giving puts the opposite sign on volatility (p.192).
- Time to expiry: calls always gain, but a deep ITM put with long life and high rates can lose value (p.192).
- Reversing the income direction (p.193).
- Calling option replication static, or equating a call at X = forward with a forward (pp.179, 183, 187).

## Original practice seeds

**A. Call exercise and time value.** S_t = 40, X = 38, r = 3%, six months left, call price 3.80. PV(X) = 38 / 1.03^0.5 = 38 / 1.01489 = 37.44. Exercise value = 2.56. Time value = 3.80 − 2.56 = 1.24. ITM since 40 > 38.

**B. Rate rise.** Same call, r rises to 6%. 1.06^0.5 = 1.02956, so PV(X) = 36.91 and exercise value = 3.09, up from 2.56, as the factor directions predict.

**C. Put bounds.** X = 100, S_t = 104, r = 2%, one year left. PV(X) = 100 / 1.02 = 98.04. Lower bound = Max(0, 98.04 − 104) = 0. Upper bound (book) = 100. A quote of 103 breaches the cap; a quote of 6 passes.

## Book slips and uncertainties

- No errors found in the book.
- The book caps a put at X, not PV(X), and prints strict inequalities on the lower bounds. Follow the book.
- Moneyness uses undiscounted X, so its in-the-money amount differs from exercise value. This is intended.
- A call slightly out of the money (S_t < X but S_t > PV(X)) still has small positive exercise value by Eq. 1. This is the notes' own reading; the book avoids the case.
