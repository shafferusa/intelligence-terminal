## Core principles
- **A table turns a chosen error rate into a cut-off.** You pick the significance level (the probability of rejecting a true null that you will tolerate), then read the critical value for that distribution. If the statistic lands beyond it, reject. The risk taken is a false rejection at that rate; the conclusion fails if the assumptions behind the distribution (normality, independence) do not hold. pp.604–612.
- **Appendix A is cumulative: area to the left of z.** Probability below a value is read directly; the area between two values is the difference of two readings; a tail cut-off is found by searching the body for the target probability. The row gives z to one decimal, the column the second decimal. The lower-tail half mirrors the upper half. pp.604–605.
- **Appendix B gives one-tail areas.** For a two-tailed test at significance alpha, use the column for alpha/2, because the rejection area is split between both ends. More degrees of freedom means a lower hurdle; the infinity row equals the normal values. p.606.
- **Chi-square and F are right-tail tables and are not symmetric.** For a left-tail chi-square cut-off use the column of the complementary right-tail probability. Chi-square tests whether a sample variance is consistent with a hypothesised one; F compares two variances or tests a regression as a whole. pp.607–611.
- **F needs the right panel and the right df order.** Each panel is a different right-tail area (0.05, 0.025, 0.01, 0.005). Columns are numerator df, rows denominator df. A two-tailed variance-equality test at alpha uses the alpha/2 panel. pp.608–611.
- **Durbin-Watson gives three zones, not two.** A statistic below dl is evidence of positive serial correlation (errors carry forward, so standard errors are understated and t-statistics look too good); above du, no evidence; between dl and du, the test is inconclusive. K counts slope parameters only; the table is for alpha = 0.05 only. p.612. The decision logic is taught in the regression modules, not printed on the page.

## Vocabulary
- Cumulative probability N(z) — chance a standard normal variable is at or below z (pp.604–605).
- Critical value — cut-off separating rejection from non-rejection at a chosen significance level (pp.604–612).
- Significance level (alpha) — tolerated chance of rejecting a true null (pp.606–612).
- Degrees of freedom (df) — independent pieces of information left after estimating parameters; a t-test on a mean uses n - 1 (pp.606–611).
- One-tailed probability — area in a single tail; the Appendix B column heads are of this kind (p.606).
- Two-tailed test — rejection area split across both tails, so each tail gets alpha/2 (p.606).
- Right-tail probability — area above the tabled chi-square or F value (pp.607–611).
- Numerator df / denominator df — the two df of an F ratio; columns vs rows (pp.608–611).
- Durbin-Watson statistic — residual-based measure used to detect first-order serial correlation (p.612).
- dl, du — lower and upper Durbin-Watson bounds; between them the test is inconclusive (p.612).
- K — number of slope parameters, excluding the intercept, in the DW table (p.612).
- Serial correlation — regression errors correlated with their own past values (p.612).

## Formulas
None in this module. Notation only: P(Z <= z) = N(z) (pp.604–605); the t and chi-square footnotes use t(df, p) and chi-square(df, p) style notation (pp.606–607). Symmetry N(-z) = 1 - N(z) fits the table values but is not stated on the page. Validity: normality for A; the usual test assumptions for B–D; E only for alpha = 0.05.

Values worth memorising (standard, one-tailed areas): z = 1.282 (10%), 1.645 (5%), 1.96 (2.5%), 2.326 (1%), 2.576 (0.5%); the t infinity row matches these (p.606).

## Traps
- Using the one-tailed t value for a two-tailed test; use alpha/2 (p.606).
- Reading chi-square as left-tail area; it is right-tail (p.607).
- Swapping df1 and df2 in the F table; columns numerator, rows denominator (p.608).
- Picking the wrong F panel; each panel is a different tail area (pp.608–611).
- Counting the intercept in K for Durbin-Watson; K is slope parameters only (p.612).
- Treating a DW value between dl and du as a rejection or non-rejection; it is inconclusive.
- Forgetting that the DW table covers alpha = 0.05 only (p.612).
- Assuming the t infinity row differs from z; it equals the normal cut-offs (p.606).

## Original practice seeds
All hypothetical.
1. **Normal area.** A standardised return has N(1.00) = 0.8413, and by symmetry N(-1.00) = 1 - 0.8413 = 0.1587. Probability the return lies between -1 and +1: 0.8413 - 0.1587 = 0.6826.
2. **More data lowers the hurdle.** A t-statistic of 2.1 on a mean, two-tailed 5%. With 11 observations (df = 10) the critical value is 2.228, so do not reject. With 31 observations (df = 30) it is 2.042, so reject. Same statistic, more data, different conclusion.
3. **Durbin-Watson logic.** A regression has K = 3 slope parameters. If DW is below dl at its n, conclude positive serial correlation; if above du, no evidence; if in between, inconclusive. A larger sample with the same DW moves the bounds and can change the verdict, so always read the bounds for the actual n and K.
