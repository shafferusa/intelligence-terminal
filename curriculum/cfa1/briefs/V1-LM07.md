## Core principles

- **CLT.** You get one sample, but means of all same-size samples cluster around the true mean with variance sigma^2/n. Larger n tightens and normalises the sampling distribution, so normal/t tables work for a mean even with non-normal returns. Symmetric populations need few observations, skewed ones about 25–30 or more. Needs independent draws and a probability-based sample (pp.313–314, 323).
- **Interval estimates.** Point estimate plus or minus critical value times standard error. Higher confidence widens it; larger n narrows it (quadrupling n halves the width). It concerns the mean, not where the data fall. Use returns, not price levels (pp.315–318).
- **VaR.** A one-sided loss cutoff at a stated confidence and horizon. Weak under fat tails, shifting distributions, misleading history and non-linear exposure such as options (pp.319–321).
- **Testing logic.** Status-quo null with equality in H0, claim in HA. Reject only when the statistic passes the critical value or p < alpha; otherwise "fail to reject", never "accept" (pp.326–334).
- **Error trade-off.** Alpha = false positive, beta = false negative, power = 1 - beta. Lowering alpha raises beta at fixed n. Bigger n or a bigger true effect raises power without changing alpha. Two-tailed tests split alpha, so reject less easily (pp.331–333).
- **Choosing the test.** Mean: t. Variance: chi-square. Two variances: F. Independent means: two-sample t. Matched data: paired t. Correlation: t, n-2 df. All assume normality or the CLT (pp.331, 335–353).
- **Significance is not importance.** Huge n makes a trivial correlation significant; significance does not mean a profitable strategy. P-hacking (re-slicing periods, dropping outliers, swapping metrics) inflates false positives; remedies are pre-specified tests, out-of-sample checks, transparency (pp.352, 354–355).
- **Non-parametric tests.** For ranks, categories, or skewed/outlier-heavy data, work with ranks or counts instead. Cost: lower power when parametric assumptions hold. Spearman catches monotonic links; chi-square tests association, not causation (pp.359–371).

## Formulas

- **SE** = sigma/sqrt(n); use s if sigma unknown; E[xbar] = mu (p.315).
- **Confidence interval**: xbar +/- z(alpha/2) x sigma/sqrt(n); z = 1.96 (95%), 2.576 (99%) (p.315).
- **VaR** = Z x sigma x P; Z one-sided (1.645 at 95%, 2.33 at 99%), sigma for the horizon, P position value; assumes normality, zero mean, linear exposure (p.320).
- **Mean**: t = (xbar - mu0)/(s/sqrt(n)), df n-1 (pp.331, 336).
- **Variance**: chi2 = (n-1)s^2/sigma0^2, df n-1; right-skewed (p.341).
- **Two independent means**: t = ((x1bar - x2bar) - Delta0)/sqrt(s1^2/n1 + s2^2/n2), df n1+n2-2 as printed; the pooled form uses sp^2 = ((n1-1)s1^2 + (n2-1)s2^2)/(n1+n2-2); equal when n1 = n2 (p.344).
- **Two variances**: F = s1^2/s2^2, df n1-1 and n2-1; larger on top for right tail (p.346).
- **Paired**: t = (dbar - mu0)/(sd/sqrt(n)), df n-1 (p.350).
- **Correlation**: t = r sqrt(n-2)/sqrt(1-r^2), df n-2 (p.351).
- **p-value**: right tail P(T >= t); left P(T <= t); two-tailed 2 x tail; reject if p < alpha (p.354).
- **Confidence level / power**: 1 - alpha / 1 - beta (p.332).
- **Spearman**: r_s = 1 - 6 sum(d_i^2)/[n(n^2-1)]; ties use average ranks (p.360).
- **Spearman test (Eq 12)**: T = r_s sqrt((n-2)/(1-r_s^2)); n > 30 use t with n-2 df, n <= 30 a Spearman table (p.360).
- **Expected count (Eq 13)**: E_ij = row share x column share x N = row total x column total / N (pp.364, 368).
- **Chi-square independence (Eq 14)**: sum (O_ij - E_ij)^2/E_ij, df (r-1)(c-1), right tail only (p.365).
- **Standardized residual (Eq 15)**: (O - E)/sqrt(E); beyond about +/-2 is notable (p.367).

## Traps

- "Accept H0" instead of fail to reject (p.310).
- Thinking larger n changes alpha; it lowers beta (p.332).
- Claim in H0, or equality missing from H0 (pp.327, 334).
- Mixing z pairs: 1.645/2.33 one-sided VaR, 1.96/2.576 two-sided intervals.
- Independent test on matched data, or paired on unrelated samples (p.349).
- Chi-square independence read as two-tailed, df = r x c, or rejection read as causation (pp.365–366).
- "Significant" taken as strong or profitable; ignoring p-hacking (pp.352, 354).
- Spearman t shortcut for n <= 30; assuming non-parametric is always better (p.360).
- A 95% interval read as "95% of observations"; p-value read as probability H0 is true (pp.316, 354).

## Original practice seeds

All hypothetical.

1. **Interval.** 36 monthly returns, mean 1.0%, sd 4.0%. SE = 4/6 = 0.667%; 95% margin 1.96 x 0.667 = 1.307%; interval -0.31% to 2.31%. With 144 months SE = 0.333%, margin 0.653%, interval 0.35% to 1.65%, excluding zero.
2. **One-tailed t.** 25 annual excess returns, mean 2.0%, sd 6.0%; H0 mu <= 0. t = 0.02/(0.06/5) = 1.667, df 24, 5% one-tailed critical about 1.711: fail to reject. With mean 2.5%, t = 2.083: reject.
3. **Chi-square 2x2.** 100 stocks: 30/20/20/30 across value/growth by payer/non-payer. Each expected count 50 x 50/100 = 25, each term 1, chi-square 4, df 1, critical 3.84: reject independence. With 28/22/22/28, chi-square = 1.44: fail to reject.
