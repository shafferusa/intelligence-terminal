## Learning outcomes

1. Describe, compare and interpret returns of financial assets and instruments (p.3, PDF 13). Taught in three blocks: total, price and distribution return (pp.6–11); arithmetic, geometric, annualised and continuously compounded returns (pp.12–19); required, excess, real, gross/net, after-tax and leveraged returns (pp.21–37).

## Core principles

- **Total return is two pieces over one base.** The investor pays the starting price and receives a price change plus any cash paid out (dividend, coupon). Both are divided by the starting price. Paper gains become realised on sale; cash is realised on receipt, and tax generally bites on realisation (pp.6–7, PDF 16–17).
- **Ex ante is forecast, ex post is outcome.** Risk is the chance the outcome falls short of the forecast; premia pay for bearing it but guarantee nothing (p.7, PDF 17; p.45, PDF 55).
- **Gains and losses change the base.** The arithmetic mean pretends each period starts from the same base. The geometric mean is the steady rate that reproduces the compounded result. Geometric is at most arithmetic, equal only with zero variability, and the gap widens with volatility (pp.12–15, PDF 22–25).
- **Annualising compounds a short return.** It assumes the same return can be earned repeatedly and stretches a short window over a year with no allowance for variability. Use it for comparison only (pp.15–16, PDF 25–26).
- **Log returns add because logs turn products into sums.** More frequent compounding raises final wealth but converges to the continuous case (pp.17–19, PDF 27–29).
- **Required return = real risk-free rate + inflation + premia.** Delaying consumption has an opportunity cost, so issuers must offer at least the risk-free rate plus pay for each risk the buyer takes (default, liquidity, maturity; market, size, value). Premia vary and may vanish (pp.21–24, PDF 31–34).
- **Fees, tax and inflation shrink what the investor keeps.** Gross judges manager skill; net is what the investor keeps; neither adjusts for inflation. Price gains and income are taxed at different rates (pp.25–31, PDF 35–41).
- **Leverage amplifies both ways.** The lender gets the borrowing rate regardless; equity holders gain only if the portfolio return beats it. A bought call is leverage without borrowing: loss capped at the premium, gain open-ended, profit only above strike plus premium (pp.32–37, PDF 42–47).

## Vocabulary

- Asset / instrument / indicator — claim (cash, equity, debt, hybrid) / tradable packaging of it / observable value paying nothing (p.6, PDF 16).
- Price return — price change over starting price (p.6, PDF 16).
- Distribution return — payout over starting price; dividend yield or current yield (p.6, PDF 16).
- Current yield — coupon over market price, below coupon rate when price exceeds par (p.12, PDF 22).
- Ex ante / ex post — expected / realised (p.7, PDF 17).
- Realised / unrealised — locked in by sale or receipt / paper gain (p.7, PDF 17).
- Arithmetic mean return — plain average of period returns (p.12, PDF 22).
- Geometric mean return — constant rate matching the compounded outcome (p.12, PDF 22).
- Annualised return — period return restated per year by compounding (p.15, PDF 25).
- Log return — natural log of the price ratio (p.17, PDF 27).
- Opportunity cost — value of the best alternative forgone (p.21, PDF 31).
- Required rate of return — minimum acceptable return (p.21, PDF 31).
- Risk premium — extra expected return for bearing one risk (pp.21–23, PDF 31–33).
- Excess / real return — above a benchmark / after inflation (p.25, PDF 35).
- Gross / net return — after trading costs / after all fund costs (p.27, PDF 37).
- Leverage — debt or derivatives enlarging exposure (p.32, PDF 42).

## Formulas

Book equation numbers; returns are per period, in decimals or percent.

- Eq 1: r_price = (P1 − P0)/P0 (p.6, PDF 16).
- Eq 2: r_distribution = Inc/P0; Inc = dividend or coupon; base is market price (p.6, PDF 16).
- Eq 3: r = r_price + r_distribution = (P1 − P0 + Inc)/P0 (p.7, PDF 17).
- Eq 4: r̄_i = (1/T) Σ_{t=1..T} r_it; it overstates compound growth (p.12, PDF 22).
- Eq 5: r̄_Gi = [Π_{t=1..T}(1 + r_it)]^(1/T) − 1; equal-length periods, each r > −100% (p.12, PDF 22).
- Eq 6: r_annualized = (1 + r_period)^c − 1; c = periods per year, may be fractional; assumes the return repeats (p.15, PDF 25).
- Eq 7: r~ = ln(P_{t+1}/P_t) = ln(1 + r); P_{t+1} = P_t e^{r~} (p.18, PDF 28).
- Eq 8: P_T/P_0 = (P_T/P_{T−1}) × … × (P_1/P_0); ln turns the product into a sum (p.18, PDF 28).
- Eq 9: r~_{0,T} = r~_{0,1} + r~_{1,2} + … + r~_{T−1,T}; growth factor e^(r×t) (p.18, PDF 28).
- Eq 10: r_rf = (1 + r_f)/(1 + infl) − 1; nominal over inflation (p.21, PDF 31).
- Eq 11: r_rf ≈ r_f − infl; fine for small or continuous rates, error compounds over long horizons (p.22, PDF 32).
- Eq 12: r_i ≈ r_rf + inf + Σ_{j=1..n} f_ij × rp_j; f = exposure, rp = premium; additive (p.22, PDF 32).
- Eq 13: (1 + r_i,t)/(1 + rf_t) − 1; benchmark may be an index (p.25, PDF 35).
- Eq 14: r_i,t − rf_t, the approximation (p.25, PDF 35).
- Eq 15: r_real = (1 + r_i)/(1 + infl) − 1 (p.25, PDF 35).
- Eq 16–18: total − transaction costs = gross; gross − management fees − administrative expenses = net; total − net = the three costs. Additive approximations (p.27, PDF 37).
- Eq 19: capital gains tax = (P1 − P0) × tax_capital gains, on a positive realised gain (p.29, PDF 39).
- Eq 20: r_net-tax = r_price × (1 − tax_capital gains) + r_distribution × (1 − tax_distribution); tax at realisation, loss offsets ignored (p.29, PDF 39).
- Eq 21: r_LP = [r_P (V_E + V_D) − V_D r_d]/V_E = r_P + (V_D/V_E)(r_P − r_d); V_E own equity, V_D borrowed, r_P whole-portfolio return, r_d borrowing rate; helps only if r_P > r_d (p.32, PDF 42).
- Equity risk premium shortcut: r_i − r_f (p.24, PDF 34).

## Traps

- Using the arithmetic mean as a growth rate (pp.12–15).
- Annualising by dividing or multiplying a period return instead of compounding (p.16).
- Multiplying log returns; they add (p.18).
- Real return as nominal minus inflation; only an approximation (p.22).
- One tax rate for price and income, or taxing unrealised gains (pp.28–31).
- Current yield taken as the coupon rate; the base is market price (p.12).
- Assuming leverage always helps; it hurts when r_P < r_d (p.33).
- Saying geometric is strictly below arithmetic; with zero variability they are equal (pp.43–44, PDF 53–54).

## Original practice seeds

All hypothetical.

1. A share costs 40.00, ends the year at 44.00 and pays 1.20 in dividends. Price return 10.0%, distribution 3.0%, total 13.0%. If it ended at 38.00, price return −5.0% and total −2.0%.
2. Annual returns +30%, −20%, +10%. Arithmetic 6.67%. Product 1.144, so geometric = 1.144^(1/3) − 1 ≈ 4.59%. 1,000 grows to about 1,144, not the 1,214 that 6.67% compounding suggests.
3. A 100,000 portfolio is financed with 40,000 borrowed at 6% (V_E = 60,000). If r_P = +10%, r_LP = 10% + (40/60)(4%) = 12.67%. If r_P = −10%, r_LP = −10% + (40/60)(−16%) = −20.67%.
