## Core principles
- **Same engine, different scenario source.** Every simulation follows four steps: set up (goal, outputs, inputs, calculations), generate scenarios, evaluate them in a calculation engine, compile results. The three methods differ almost only in step 2. Simulation suits non-linear or path-dependent payoffs (pp.456–457, 502).
- **Historical simulation replays the past on today's positions.** Apply actual past market moves to current holdings and read the loss distribution. It assumes the past covers future possibilities, failing in regime shifts. No distribution is imposed, so fat tails, skew and volatility clustering flow through, and same-day data keep correlations intact (pp.458–459, 467).
- **Equity P/L uses log returns converted back to money; bonds use yield changes.** Each scenario's money change per position is its value times (e^r − 1), summed across positions. A bond's own price history is the wrong input (its maturity keeps shortening); use yield or benchmark changes and revalue today's bond by discounting cash flows (pp.459, 461, 467).
- **Bootstrapping resamples the sample with replacement.** Each of n observations has probability 1/n on every draw, so earlier draws never affect later ones. The sample stands in for the population, giving a sampling distribution for any statistic. It cannot produce values outside the observed range, ignores time dependence, and carries the sample's bias and drift, so a bootstrapped option value is not a risk-neutral price (pp.469, 476, 479–481).
- **Monte Carlo draws from a distribution the analyst chooses.** For options: simulate risk-neutral paths (growth at the risk-free rate), compute each payoff, average, discount at the risk-free rate. One path says nothing. More runs improve precision, not the validity of assumptions; mis-specification (e.g. constant volatility) is the main risk (pp.482–489, 490, 494).
- **Correlated risk factors via Cholesky.** Draw independent standard normals, then mix them so the outputs have the target volatilities and correlation. It produces correlated normals, not non-normal variables, and does not remove sampling noise (pp.490–494, 508).
- **Method choice is a trade-off.** Historical: low-to-moderate computation, real data, backward-looking. Bootstrap: moderate computation, few assumptions, suits small samples. Monte Carlo: highest computation, flexible and forward-looking, model-dependent (p.495, Exhibit 32).

## Vocabulary
- Simulation — computing a target output across many scenarios (p.456).
- Historical simulation — applying actual past changes to current exposures (p.458).
- Volatility clustering — turbulent periods tend to follow turbulent ones, calm follows calm (p.459).
- Fat tails / leptokurtic — extremes more frequent than a normal curve implies (pp.458–459).
- Value at risk (VaR) — loss exceeded with a small stated probability over a horizon; 95% VaR is the 5th percentile of P/L (p.459).
- Proxy — stand-in instrument for a security with too little history (p.467).
- Resampling / bootstrapping — repeated draws with replacement from one sample (p.469).
- Sampling with replacement — drawn item goes back; probability 1/n each draw (p.469).
- Monte Carlo simulation — random draws from assumed distributions (pp.458, 482).
- Path-dependent (Asian-style) option — payoff depends on the price path or its average (pp.485–486).
- Cholesky decomposition — factorisation that turns independent normals into correlated ones (p.490).
- Geometric Brownian motion — lognormal price process (p.499).

## Formulas
- **Log return:** r_t = ln(P_t / P_{t−1}). Unitless; adds across periods (p.459).
- **Bond value from simulated yields:** PV = Σ CF_t / (1 + y_t)^t, t = 1..T. CF = cash flow, y = yield for that maturity (p.459).
- **P/L from log return:** P/L = position value × (e^r − 1). Using r directly is wrong (p.461, Eq. 2).
- **Two-asset parametric VaR:** σp² = D₁²σ₁² + D₂²σ₂² + 2·D₁D₂·ρ·σ₁σ₂; VaR = z × σp. D = amounts invested, σ = daily volatility. Assumes normal returns, zero mean (a daily-VaR convention). Book uses z = 1.96 as 95%; one-tailed 95% is 1.645 (p.463, Eq. 3).
- **Historical VaR by rank:** rank = tail probability × N; if not whole, interpolate between neighbouring ordered losses, weighting each by how close the rank is to it (p.463).
- **Linear interpolation:** x = x₁ + (Percentile − p₁)/(p₂ − p₁) × (x₂ − x₁) (pp.465–466, Eq. 4).
- **European call payoff:** max(P_T − K, 0) (p.471, Eq. 5).
- **Bootstrap terminal price:** P_T = P₀ × e^(sum of n resampled log returns), then the payoff formula (p.474).
- **Risk-neutral log return per step:** r_t = (r_f − σ²/2)·s + σ·√s·X, s = step in years, X ~ N(0,1); P_t = P_{t−1}·e^{r_t}. Assumes lognormal prices, constant volatility (p.484, Eq. 6).
- **Asian option:** payoff = max(P_T − average price over life, 0); value = E[payoff] × e^(−rT), continuous discounting (pp.485–486, 489, Eq. 7).
- **Cholesky, two variables:** X₁ = σ₁Z₁; X₂ = σ₂(ρZ₁ + √(1−ρ²)Z₂); Z₁, Z₂ independent N(0,1). Gives zero means, variances σ₁², σ₂², covariance ρσ₁σ₂ (p.491, Eqs. 8–13).
- **GBM step:** P_{t+Δt} = P_t × exp[(r − 0.5σ²)Δt + σ√Δt·Z]; Excel: =P*EXP((r-0.5*σ^2)*Δt+σ*SQRT(Δt)*NORM.INV(RAND(),0,1)). Same step as above (p.499, Eq. 14; Excel line p.500).

## Traps
- Bootstrapping is not historical simulation: bootstrap resamples with replacement and repeats; historical replays each observation once as it occurred (p.469).
- Historical simulation needs no separate correlation model; same-day data preserve it (p.467).
- Using r instead of e^r − 1 for P/L; using a bond's own price history instead of yield changes (pp.461, 467).
- Drift in the lognormal step is r − σ²/2, not r; and risk-neutral pricing discounts at the risk-free rate (p.484).
- Judging one Monte Carlo path, or thinking more runs fix a wrong model (pp.488–490, 494).
- Believing Cholesky creates non-normal variables, or that bootstrapping fills missing data or corrects bias (pp.506, 508).
- Cholesky second-variable weight on Z₁ is ρ and on Z₂ is √(1−ρ²), not (1−ρ) (p.491).

## Original practice seeds
All hypothetical.
1. **Historical VaR.** 100 daily P/Ls on a USD2m position; 5th-worst loss USD36,000, 6th-worst USD34,000. Rank = 5% × 100 = 5.0, so 95% one-day VaR = USD36,000. With 110 observations rank = 5.5, VaR = (36,000 + 34,000)/2 = USD35,000 (same 5th/6th values assumed).
2. **Bootstrap.** Sample of 4 weekly log returns {+1%, −2%, +3%, 0%}, start price USD50. Draw 3 with replacement: +3%, +3%, −2%; sum = +4%; P_T = 50·e^0.04 = USD52.04. Probability of drawing −2% on any draw = 1/4 regardless of earlier draws.
3. **Cholesky.** σ₁ = 1%, σ₂ = 3%, ρ = 0.5, Z₁ = 1.0, Z₂ = −1.0. X₁ = 1%. X₂ = 3% × (0.5 − 0.8660) = −1.098%. With ρ = 0.9: √(1−0.81) = 0.4359, X₂ = 3% × (0.9 − 0.4359) = 1.392%.
