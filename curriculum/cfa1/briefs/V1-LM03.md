## Core principles

- **Two returns, two questions.** Time-weighted (TW) return asks how well the manager invested: cut the period at every cash-flow date and chain the subperiod returns, so flow size and timing drop out. Money-weighted (MW) return asks what the investor actually earned: the IRR of the investor's own flows. The investor controls contributions and withdrawals; a public-market manager usually does not (pp.75–77).
- **Timing drives the gap.** Identical investment returns give different results if money arrived before a loss rather than after. MW exceeds TW when large flows preceded strong periods and falls below it when they preceded weak ones. With tiny flows the two converge (pp.75–83).
- **GIPS convention.** TW is the default for public-market managers; MW is allowed only where the manager controls external flows and the vehicle is closed-end, fixed-life, drawn on demand or holds large illiquid assets. MW can mislead when flows are frequent and large (pp.77, 84).
- **Weighting is the index's personality.** Index level is a weighted sum scaled by a divisor. Cap weighting follows market value: weights drift with prices, so no price-driven rebalancing, but it concentrates in past winners. Float adjustment counts only tradable shares. Price weighting lets high share prices dominate regardless of company size. Equal weighting tilts toward small firms and needs rebalancing (trading cost). Fundamental weighting sizes by earnings or similar, tilts to value and needs rebalancing (pp.90–104).
- **Price vs total return.** Same constituents; the total return index also reinvests distributions, so it grows faster, and the gap widens with horizon (pp.89–90).
- **Index maintenance.** Rebalancing restores target weights among current members (equal-weight sells winners, buys losers). Reconstitution changes membership; trackers must trade, and expected additions tend to rise beforehand. A split forces a divisor change to keep the level continuous, yet still lowers that stock's weight in a price-weighted index (pp.105–109).
- **Same stocks, different answer.** Weighting alone can change index return over one period, so benchmark must match strategy (pp.110–115).

## Vocabulary

- Time-weighted return — compound growth from chaining subperiod returns split at each cash flow (p.76)
- Money-weighted return — IRR of the investor's cash flows (p.77)
- IRR — rate that sets present value of all flows to zero (p.77)
- GIPS — voluntary CFA Institute performance standards; favour TW (p.77)
- Security market index — aggregate indicator of a market or segment (p.87)
- Passive vs active investing — replicate an index vs try to beat it (p.88)
- Price return / total return index — price change only vs plus reinvested income (p.89)
- Market-cap weighting — weight by shares outstanding times price (p.91)
- Divisor — scaling constant adjusted so the level stays continuous (pp.91, 99–100)
- Market float; float-adjusted; free-float-adjusted — tradable shares; also excludes foreign-barred shares (pp.93–94)
- Fundamental weighting — weight by an economic measure (p.98)
- Price weighting; stock split — weight by share price; more shares, lower price, same value (p.99)
- Equal weighting — 1/N each at setup (pp.100–101)
- Rebalancing vs reconstitution — restore weights vs change membership (p.105)
- Banding — buffer that cuts reconstitution turnover (p.109)

## Formulas

1. **TW (Eq. 1, p.76):** r_TW = [(1+r_1)...(1+r_T)] - 1 (cumulative); annualized over T years, raise the product to 1/T and subtract 1 (p.85). r_t = subperiod return between cash-flow dates. Needs valuation at each flow date.2. **MW (Eq. 2, p.77):** 0 = sum over t=0..T of CF_t/(1+r_MW)^t. CF_t = net flow from the investor's view (contributions negative; withdrawals and ending value positive); r_MW is per period, so annualize. Use an IRR function; several sign changes can give multiple IRRs.
3. **Annualizing (p.82):** (1 + r_period)^(periods per year) - 1.
4. **Price / total return (p.89):** P_(t+1)/P_t - 1; (P_(t+1) + Div_(t+1))/P_t - 1.
5. **Cap weight (Eq. 4–5, p.91):** w_i = Q_i P_i / sum(Q_j P_j); V = sum(Q_i P_i)/D. Q = shares, P = price, D = divisor.
6. **Float-adjusted (Eq. 6, p.94):** w_i = f_i Q_i P_i / sum(f_j Q_j P_j), f_i between 0 and 1; V = sum(f_i Q_i P_i)/D. Changes the divisor, not the base level.
7. **Fundamental (Eq. 7, p.99):** w_i = F_i / sum(F_j).
8. **Price weight (Eq. 8–9, p.99):** w_i = P_i / sum(P_j); V = sum(P_i)/D. Post-split divisor = new price sum / old index value (p.108).
9. **Equal weight (Eq. 10–11, p.101):** w_i = 1/N; V = sum(n_i P_i)/D with n_i P_i equal at setup.
10. **Index return (p.97):** V_1/V_0 - 1 = sum(w_i r_i), start-of-period weights; equals the simple average for equal weighting only from an equal-weight start (p.104). Total return index: sum(n_i(P_i + Div_i))/D with reinvestment.

## Traps

- Calling TW the investor's return; it isolates the manager.
- Reversing the MW/TW gap; ask whether big money met good or bad returns.
- Annualizing a sub-year IRR by multiplying instead of compounding.
- Averaging arithmetically instead of linking geometrically.
- Equating high share price with a big company; splits cut a stock's price-weighted influence, and the divisor only preserves the level.
- Thinking cap-weighted indexes never trade; they still change at reconstitution.
- Believing float adjustment changes the base value; it changes weights and divisor.
- Inverting the price ratio in a return, or forgetting the divisor cancels in a return.

## Original practice seeds

**H1 (hypothetical): TW vs MW when flow size changes.** Annual periods, flows at start of each year, terminal value at end of year 2. Invest 100 at the start of year 1 (return +20%), add 120 at the start of year 2, year 2 return -10%. TW = sqrt(1.20 x 0.90) - 1 = 3.92% a year. MW: flows -100, -120, +216 (240 x 0.9); solve 216x^2 - 120x - 100 = 0 with x = 1/(1+r), x = 1.0127, r = -1.26%. If only 12 is added: end value 118.8, r = +3.16%, TW still 3.92%. MW moved because less money met the bad year.

**H2 (hypothetical): price-weighted index and split.** Prices X = 60, Y = 30, Z = 10, divisor 3, index 33.33. X up 10% gives sum 106, index +6.0%; Z up 10% gives sum 101, +1.0%; an equal-weighted index rises 3.33% either way. X splits 2:1 to 30: sum 70, new divisor 70/33.33 = 2.1, index stays 33.33, X's weight falls from 60% to 42.9%.

**H3 (hypothetical): float adjustment.** Two stocks, 1,000 shares each at 10; P fully floated, R 50% floated. Float-adjusted weights 66.7% / 33.3% (unadjusted 50/50). R up 20%, P flat: unadjusted index +10%, float-adjusted +6.67%.
