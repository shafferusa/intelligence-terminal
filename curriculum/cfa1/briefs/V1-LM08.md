## Core principles

- **Weighted-average return, start-of-period weights.** With no trading, winners grow and weights drift toward them, so each period needs its own opening weights. Style drift differs: holdings change character (pp.387–390).
- **Risk is not the average of asset risks.** Variance sums weight x weight x covariance. Correlation below 1 lets swings partly cancel; risk falls below the safest asset only if correlation is low enough. (pp.391–394).
- **Diversification has a floor.** Each asset's own variance fades as holdings grow; average covariance stays. What remains is systematic risk; asset-specific risk is removed. Higher average correlation raises the floor. Rule of thumb: about 20–30 low-correlation assets capture most of the benefit (pp.405–408).
- **Frontier logic.** Mixes fill a region; the efficient frontier is its upper-left edge. The global minimum-variance portfolio is the leftmost tip and ignores return; points below it are dominated (pp.413–419).
- **Risk-free asset straightens the frontier.** Mixing it with one risky portfolio gives a straight CAL with slope equal to the Sharpe ratio, constant along it. Risk-averse investors lend more; tolerant ones borrow at the risk-free rate and exceed 100% risky. The best risky portfolio is the tangency point, not the minimum-variance one (pp.434–436).
- **Utility picks the point.** Highest score wins, even if negative. Risk-averse indifference curves slope up and steepen: more risk needs more return (pp.429–433).
- **CAPM prices only systematic risk.** If everyone holds the market portfolio, only covariance with the market matters; asset-specific risk is diversifiable so earns no premium. Fails with differing views, taxes, costs, non-normal returns, correlations rising in stress, estimation error (pp.437–445).

## Vocabulary

- Portfolio drift — weights shift because returns differ, no trades (p.388).
- Style drift — holdings change character, straying from strategy (p.388).
- Covariance — unscaled co-movement, return-squared units (p.392).
- Correlation — covariance scaled to -1 to +1 (p.392).
- Variance-covariance matrix — symmetric table, variances on diagonal (p.395).
- Systematic vs unsystematic risk — market-wide vs asset-specific (p.408).
- Efficient frontier — most return for each risk level (p.414).
- Global minimum-variance portfolio — lowest-variance feasible mix (p.415).
- Tangency portfolio — highest Sharpe ratio on the frontier (p.416).
- Risk-averse / neutral / seeking — wants compensation / cares only about expected return / values risk (p.429).
- Indifference curve — equal-utility risk-return pairs (p.431).
- Capital allocation line — risk-free asset plus a risky portfolio (p.435).
- Market portfolio — all risky assets at market-value weights (p.436).
- Mutual fund theorem — market portfolio plus risk-free serves everyone (p.436).
- Beta — covariance with market over market variance (p.438).
- Security market line — expected return against beta (p.438).

## Formulas

Decimals throughout; variance in return-squared units.

1. r_P,t = SUM_i w_i,t-1 r_i,t, r_i,t = (P_t - P_t-1 + Div_t)/P_t-1; E[r_P] = SUM w_i E[r_i] (pp.387–388, 392).
2. Geometric: [PROD(1 + r_P,t)]^(1/T) - 1, at or below the arithmetic mean (pp.387–388).
3. sigma_P^2 = SUM_i SUM_j w_i w_j sigma_ij; sigma_ij = rho_ij sigma_i sigma_j (pp.391–392).
4. Two assets: sigma_P = sqrt(w1^2 s1^2 + w2^2 s2^2 + 2 w1 w2 rho s1 s2); if covariance given, use it instead of rho s1 s2.
5. Scenarios: E[r_P] = SUM p_M r_P,M; variance = SUM p_M (r_P,M - E[r_P])^2 (p.400).
6. Equal weights: sigma_P^2 = sigma^2/N + (1 - 1/N) rho_bar sigma^2, large N approaches rho_bar sigma^2 (pp.405–406).
7. w_A = (sigma_B^2 - sigma_AB)/(sigma_A^2 + sigma_B^2 - 2 sigma_AB); w_B = 1 - w_A (p.417).
8. Target return: w_A = (r_p - r_B)/(r_A - r_B); with risk-free: w_risky = (r_p - r_f)/(r_risky - r_f), sigma_p = w_risky sigma_risky (pp.421–423).
9. Sharpe = (E[r_p] - r_f)/sigma_p (pp.423, 436).
10. U = E[r] - 0.5 A sigma^2; A > 0 averse, 0 neutral, < 0 seeking; typical A is 2 to 3 (p.430).
11. CAL: E[r_p] = w_f r_f + (1 - w_f) E[r_Q]; sigma_p = (1 - w_f) sigma_Q; E[r_p] = r_f + [(E[r_Q] - r_f)/sigma_Q] sigma_p. Assumes zero-risk asset, equal borrowing and lending rates; w_f < 0 is borrowing (p.434).
12. CML: E[r_p] = r_f + [(E[r_m] - r_f)/sigma_m] sigma_p (p.436).
13. beta_i = sigma_i,m / sigma_m^2 = rho_i,m sigma_i/sigma_m; market beta 1 (p.438).
14. CAPM/SML: E[r_i] = r_f + beta_i (E[r_m] - r_f) (pp.438, 440).
15. Regression: r_i - r_f = alpha + beta_i (r_m - r_f) + error (p.440).

## Traps

- Plain sum of period returns is not the compounded return; arithmetic mean exceeds geometric when returns vary.
- Variance is not standard deviation: take the square root.
- Given covariance, do not multiply by the SDs again; convert percentages to decimals.
- Missing the factor 2 or the squares in the cross term; with three assets count each pair twice.
- Minimum-variance is not optimal; with a risk-free asset the tangency point is.
- High beta need not mean high total SD; CAPM ranks by beta.
- More assets alone does not help; high average correlation sets the floor.
- Utility can be negative; over 100% risky is borrowing, not an error. Sharpe uses total risk, beta systematic risk; SML is for securities, CAL/CML for portfolios.
