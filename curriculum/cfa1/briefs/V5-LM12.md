## Learning outcomes

1. Explain how the CAPM and the market model estimate a company's cost of equity. Taught in "Use of the Market Model and CAPM..." with Beta Estimation and MRP estimation (p.470–489; PDF 480–499).
2. Describe arbitrage pricing theory and why multi-factor models matter in equity investing. Taught in the APT sections (p.490–499; PDF 500–509).

## Core principles

- **Cost of equity is the shareholders' required return.** It discounts FCFE and feeds WACC for FCFF. Equity is paid last, so holders need a premium for risk they cannot diversify. The estimate can move with no change in cash flows, which moves value (p.467–470, PDF 477–480).
- **CAPM prices market risk only.** Required return = risk-free rate + beta x MRP. At one date in one market, only beta separates stocks. Beta = correlation x stock volatility / market volatility: more stock volatility or tighter tracking raises it; more market volatility lowers it. It fails if other risks are priced (p.471–472, PDF 481–482).
- **A higher risk-free rate need not raise the cost.** Holding the expected market return fixed shrinks the MRP, so with beta above 1 the cost can fall (p.473, PDF 483).
- **Regression beta is a noisy estimate.** It is the slope of stock on market returns, typically weekly or monthly over 1–5 years. The market model uses raw returns and gives similar betas. Raw beta is often blended toward 1.0 because extreme betas revert. Results depend on index, horizon and frequency; low R-squared and a large standard error flag a poor beta. Disclose choices (p.474–479, PDF 484–489).
- **Industry beta when the stock's own beta is unreliable** (private, newly listed, recent leverage change, noisy regression). Strip peers' leverage, then add the target's own leverage and tax rate. It assumes equal business risk. Debt only adds to beta, so levered is never below unlevered. A peer portfolio gives a tighter estimate (p.480–483, PDF 490–493).
- **MRP is the shakiest input.** Historical: average index return minus average government return. Implied: index return from price, next dividend and growth, minus the current government rate. Rising prices raise the historical MRP but lower the implied one. A developing market adds a country risk premium, scaled by equity-to-bond volatility. Run sensitivities (p.484–489, PDF 494–499).
- **APT and multi-factor models.** Expected return = risk-free rate + sum of exposure x factor premium. APT names no factors. The common four-factor set is market, size, value, momentum. Non-market factors are zero-investment long-short portfolios, so an average stock has exposures 1, 0, 0, 0 and negative betas are normal (large-cap or growth tilts). CAPM can overstate or understate cost depending on omitted exposures. Premiums are period-dependent historical averages, and many published factors are probably data-mined (p.490–499, PDF 500–509).

## Vocabulary

- Cost of equity — return shareholders require; FCFE discount rate (p.470, PDF 480).
- CAPM — single-factor model of required return (p.471, PDF 481).
- Market risk premium — expected market return minus risk-free rate (p.471, 484).
- Beta — covariance with market over market variance (p.472, PDF 482).
- Raw vs adjusted beta — regression estimate vs blend with 1.0 (p.475, PDF 485).
- R-squared, standard error of beta — noise gauges (p.478, PDF 488).
- Levered / unlevered beta — with / without financial leverage (p.480, PDF 490).
- Country risk premium — extra premium for a riskier country (p.484, PDF 494).
- Implied MRP — forward-looking MRP from price, dividend, growth (p.486–487, PDF 496–497).
- Arbitrage pricing theory — multi-factor framework, factors unspecified (p.491, PDF 501).
- SMB, HML, UMD — size, value, momentum long-short factors (p.491–492, PDF 501–502).

## Formulas

1. **CAPM/SML:** E[r_i] = r_f + beta_i x (E[r_m] - r_f). MRP = E[r_m] - r_f; beta unitless; % per year; market is the only factor. Intuition: base rate plus a price per unit of market risk. p.471 (PDF 481).
2. **Beta:** beta_i = cov(i,m)/var(m) = rho x sd_i / sd_m; so rho = beta x sd_m / sd_i. Same-period sds. p.472 (PDF 482).
3. **Adjusted beta:** w1 x Raw + w2 x 1.0, w2 = 1 - w1; Bloomberg w1 about 0.67. Pulls toward 1.0. p.475 (PDF 485).
4. **Excess-return regression:** r_it - r_ft = alpha_i + beta_i (r_mt - r_ft) + e_t. p.476 (PDF 486).
5. **Market model:** r_it = alpha_i + beta_i x r_mt + e_it. No risk-free series needed. p.476 (PDF 486).
6. **Unlever:** beta_u = beta_L,comps / [1 + (1 - t) x D/MVE]. Averages across comparables; D/MVE is debt over market value of EQUITY. p.480 (PDF 490).
7. **Relever:** beta_L,firm = beta_u x [1 + (1 - t) x D_firm/MVE_firm], firm's own tax and leverage. p.482 (PDF 492).
8. **Ordering:** beta_L,comps >= beta_u <= beta_L,firm (positive debt, tax below 100%). p.483 (PDF 493).
9. **CAPM with country risk:** E[r_i] = r_f + beta_i x (MRP_developed + CRP); CRP = sovereign spread x (equity sd / bond sd), annualised. Spread in a reserve currency, r_f to match. p.484 (PDF 494).
10. **Index return:** E[r_m] = Div_1,m / P_0,m + g_l,m; Div_1 is next year's dividend; g long-run growth. p.486–487 (PDF 496–497).
11. **Implied MRP:** E[r_m] - r_f (current government rate). p.487 (PDF 497).
12. **APT:** E[r_i] = r_f + sum over k of beta_i,k x E(f_k); exposure x factor premium. p.491 (PDF 501).
13. **Four-factor:** E[r_i] = r_f + b_Market x E(r_m - r_f) + b_Size x E(SMB) + b_Value x E(HML) + b_Momentum x E(UMD). Premiums in the same period as r_f (monthly x 12). p.491–492 (PDF 501–502).

## Traps

- Beta is not correlation; it also scales by relative volatility.
- Unlevering with debt/(debt + equity) instead of debt/market equity.
- Treating peers' average levered beta as unlevered; that holds only with no debt.
- Assuming adjusted beta is always lower; low betas rise toward 1.0.
- Using the last dividend rather than next year's in the implied-return formula.
- Geometric is below arithmetic; the long-bond MRP is below the T-bill MRP.
- CRP is not the bare spread (scale by the volatility ratio), and it goes inside the bracket with the MRP, before multiplying by beta.
- Monthly factor premiums must be annualised before adding to an annual r_f.
- A negative size or value beta is not an error; it signals a large-cap or growth tilt.
- Cost is not proportional to beta, since r_f is a fixed intercept; multi-factor cost is not always above or below CAPM.

## Original practice seeds

1. *(Hypothetical)* r_f = 3%, MRP = 5%, beta 1.4: cost = 3 + 7 = 10.0%. If MRP rises to 6%: 3 + 8.4 = 11.4%. Same cash flows, higher discount rate, lower value.
2. *(Hypothetical)* Peers: average levered beta 1.20, D/MVE 25%, tax 30%. Unlevered = 1.20 / (1 + 0.7 x 0.25) = 1.20 / 1.175 = 1.0213. Target with D/MVE 80%, tax 25%: 1.0213 x (1 + 0.75 x 0.80) = 1.0213 x 1.60 = 1.634. At D/MVE 40%: 1.0213 x 1.30 = 1.328.
3. *(Hypothetical)* Two-factor APT, r_f = 2%, premiums 5% (market) and 2% (size), exposures 1.1 and 0.5: 2 + 5.5 + 1.0 = 8.5%. With size exposure -0.5: 2 + 5.5 - 1.0 = 6.5%.
