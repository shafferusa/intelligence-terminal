## Learning outcomes
1. Describe traits of major asset classes relevant to portfolios (pp.4–11, 31–35).
2. Explain risk aversion and its portfolio implications (pp.12–20).
3. Explain how utility and the capital allocation line fix the optimal portfolio (pp.18–20, 40–47).
4. Calculate and interpret mean, variance, covariance, correlation (pp.21–29; formulas only).
5. Calculate and interpret portfolio standard deviation (pp.21–30).
6. Describe how imperfectly correlated holdings change portfolio risk (pp.24–26, 30–35, 36–39).
7. Describe the minimum-variance frontier, efficient frontier and global minimum-variance portfolio (pp.36–39).

## Core principles
- **History is a proxy** (p.4). Expected return is what the marginal investor requires: real risk-free rate, inflation and risk premium, compounded. Past averages rarely match it.
- **Mean-variance hides some risks** (pp.8–11). It assumes normal returns and efficient markets; skew, fat tails and trading costs sit outside it.
- **Utility trades return against risk** (pp.12–17). Utility is personal and ordinal; a risk-free asset gives everyone the same utility. Steeper curves mean more aversion.
- **Risk-free plus one risky asset gives a straight line** (pp.18–20). Borrowing is a negative risk-free weight. The investor sits where the highest reachable indifference curve touches the line; more aversion means nearer the risk-free end.
- **Portfolio risk is a covariance story** (pp.21–30). Return is a weighted average; variance adds cross terms. Correlation changes risk, never expected return. Only at perfect positive correlation is risk the weighted average. With many equal weights, risk converges to the average covariance, not zero.
- **Currency adds risk** (pp.28–29). A foreign asset's domestic return combines local and exchange-rate returns, so a safe foreign bond can look riskier at home.
- **Frontier, CAL, tangency** (pp.36–47). The left tip of the frontier is the global minimum-variance portfolio; the branch above it is efficient. With a risk-free asset the steepest line touches the frontier at the optimal risky portfolio, held by everyone; preference only sets the lend/borrow split (p.41).

## Vocabulary
- Expected return — forward-looking return investors require (p.4).
- Geometric mean — compounded return, never above arithmetic mean (p.6).
- Skewness — asymmetry; negative means long left tail (p.9).
- Value at risk — loss exceeded with stated probability (footnote 2, PDF 20).
- Risk averse / neutral / seeking — prefers sure thing / indifferent / prefers gamble at equal expected value (pp.12–13).
- Risk aversion coefficient A — weight on variance in utility (p.14).
- Indifference curve — equal-utility risk-return pairs (p.14).
- Capital allocation line — mixes of risk-free asset and a risky portfolio (p.18).
- Global minimum-variance portfolio — lowest-risk all-risky portfolio (p.39).
- Two-fund separation — all hold risk-free asset plus one risky portfolio (p.41).

## Formulas
1. 1 + E(R) = (1 + r_rF)(1 + E(π))(1 + E(RP)); real rate, inflation, premium; decimals; multiplicative. p.4.
2. U = E(r) − 0.5·A·σ²; decimals, A unitless; ordinal; variance penalised by aversion. p.14.
3. E(Rp) = w1·Rf + (1 − w1)·E(Ri); σp = (1 − w1)·σi; negative w1 is borrowing. p.18.
4. CAL: E(Rp) = Rf + [(E(Ri) − Rf)/σi]·σp; slope is reward per unit of risk. p.18.
5. Rp = Σ wi·Ri, Σ wi = 1; single period, constant weights. p.22.
6. σp² = Σ wi²σi² + Σ_{i≠j} wi wj Cov; Cov = ρσiσj. p.22.
7. σp² = w1²σ1² + w2²σ2² + 2w1w2ρ12σ1σ2; decimal-squared units. pp.22–23.
8. ρ = +1: σp = w1σ1 + w2σ2; ρ < 1: lower; ρ = −1: σp = |w1σ1 − w2σ2| (notes' own derivation, not in text). pp.24–25.
9. R_D = (1 + R_lc)(1 + R_FX) − 1; σ_D = √(σ_lc² + σ_FX² + 2ρσ_lcσ_FX). pp.28–29.
10. N equal weights: σp² = σ̄²/N + ((N−1)/N)Cov̄; common σ, ρ: √(σ²/N + ((N−1)/N)ρσ²). pp.30–31.
11. Add a new asset if its Sharpe ratio exceeds ρ(new, portfolio) × portfolio Sharpe ratio. pp.35–36.

## Traps
- Treating historical mean as expected return.
- Using percentages instead of decimals in utility (p.17).
- Averaging SDs; valid only at ρ = +1.
- Thinking correlation moves expected return (p.27).
- Assuming more assets erase risk; the floor is average covariance (p.30).
- Confusing global minimum-variance with the optimal risky portfolio (pp.39, 41).
- Forgetting currency risk on foreign bonds.
